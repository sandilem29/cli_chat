
## About Tobi Ai

Tobi AI is basically a local AI assistant thats based on chatgpt model, that can run directly from your terminal, similar how a chatbot assistant will do.

## Installation/Setup

1. you must have a .env variable on the root directory with your openai API key reference is on .env.example
2. run cargo build on your root directory (to fetch all the dependencies or crates needed)
3. run cargo run this will run the Tobi AI bot 


## How its works

Similar how AI work you can ask any random questions and will respond, its runs on while true indefinite loop to exit the assistant you simple type "exit" on the terminal
